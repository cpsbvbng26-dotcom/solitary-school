デザインに関する法的な扱い

自己実験としての名乗りの頁（index.html）と、この頁の見た目について書きます。

この頁について

扱うのは、二つの頁の見た目の部品です。書体、ロゴ・印・ファビコン・共有用の画像、図、配色、配置、外から読む素材を扱います。

部品ごとに、誰が作ったか、どこから来たか、権利と許諾がどうなっているか、どの法令の条にどう関わるかを書きます。

書いてあるのは運営者の側の理解です。法的な助言ではありません。弁護士の確認は受けていません。

条文は、運営者の別のリポジトリの verification/statutes-texts.json（コミット 85dd680、e-Gov 法令 API から 2026-11-22 に取り寄せ）の写しのとおりに引きます。引く条だけを、このリポジトリの verification/statutes-design.json に一字一句そのまま写しました。verification/check_design.js が、写しの文と sha256 と、この頁の引用を突き合わせます。

このリポジトリは、GitHub Pages で配っていません。2026-11-22 に GitHub の API で読んだリポジトリの has_pages は false でした。リポジトリの中にも、頁を配るワークフローと CNAME のファイルはありません。二つの頁は、リポジトリのファイルとして置いてあります。

この頁の事実は、2026-11-22 に確かめたものです。

著作権

著作権法第2条第1項第1号は、著作物を次のように定めています（写しの全文）。

一 著作物 思想又は感情を創作的に表現したものであつて、文芸、学術、美術又は音楽の範囲に属するものをいう。

著作権法第10条第1項第4号は、著作物の例として次のものを挙げています（写しの全文）。

四 絵画、版画、彫刻その他の美術の著作物

二つの頁の見た目は、一段の組み、罫線、端末の明朝体、落ち着いた色の組み合わせでできています。これが「思想又は感情を創作的に表現したもの」に当たり、美術の著作物に入るかは、条文の文からは決まりません。運営者は、この見た目を美術の著作物だと主張しません。

許諾は、このリポジトリの LICENSE と LICENSE-CODE のとおりです。本文は CC BY 4.0、検査のスクリプトは MIT です。この頁は、どの許諾も変えません。

著作権法第19条と第20条は、著作者の人格の権利を定めています。第19条は、第1項の初めの文を写しから切り出しました。

著作者は、その著作物の原作品に、又はその著作物の公衆への提供若しくは提示に際し、その実名若しくは変名を著作者名として表示し、又は著作者名を表示しないこととする権利を有する。

著作権法第20条は、第1項を写しから切り出しました。

著作者は、その著作物及びその題号の同一性を保持する権利を有し、その意に反してこれらの変更、切除その他の改変を受けないものとする。

根の LICENSE（CC BY 4.0）の Section 2 の b の 1 は、次のとおりです。

Moral rights, such as the right of integrity, are not licensed under this Public License, nor are publicity, privacy, and/or other similar personality rights; however, to the extent possible, the Licensor waives and/or agrees not to assert any such rights held by the Licensor to the limited extent necessary to allow You to exercise the Licensed Rights, but not otherwise.

この文の要旨は、人格の権利は許諾の対象にならず、許諾者は、許諾した権利を使えるようにするのに要る限りで、その権利を行使しない、というものです。訳ではありません。

他人の素材は使っていません。画像、書体のファイル、ほかのサイトの CSS は、このリポジトリにありません。著作権法第21条は、複製の権利を著作者のものとしています（写しの全文）。

（複製権） 第二十一条 著作者は、その著作物を複製する権利を専有する。

他人の著作物を複製して置いていないので、他人の著作物の許諾の文と条件に従うべきものはありません。

商標・意匠・不正競争

このリポジトリの記録には、頁の題、名、見た目を、商標や意匠として出願した記録も、登録した記録もありません。特許庁の記録で登録の有無を確かめてはいません。

商標法第25条は、商標権の効力を次のように定めています（写しの全文）。

（商標権の効力） 第二十五条 商標権者は、指定商品又は指定役務について登録商標の使用をする権利を専有する。 ただし、その商標権について専用使用権を設定したときは、専用使用権者がその登録商標の使用をする権利を専有する範囲については、この限りでない。

二つの頁は、何も売りません。教えることもしません。index.html の経験の表に出る武道の名は、稽古の事実を述べる文に出るもので、商品や役務の表示として使っていません。他人の登録商標と照らし合わせては確かめていません。

意匠法第2条は、第1項を写しから切り出しました。

この法律で「意匠」とは、物品（物品の部分を含む。以下同じ。）の形状、模様若しくは色彩若しくはこれらの結合（以下「形状等」という。）、建築物（建築物の部分を含む。以下同じ。）の形状等又は画像（機器の操作の用に供されるもの又は機器がその機能を発揮した結果として表示されるものに限り、画像の部分を含む。次条第二項、第三十七条第二項、第三十八条第七号及び第八号、第四十四条の三第二項第六号並びに第五十五条第二項第六号を除き、以下同じ。）であつて、視覚を通じて美感を起こさせるものをいう。

意匠法第2条は、画像を、機器の操作の用に供されるものか、機器がその機能を発揮した結果として表示されるものに限っています。二つの頁の画面がこの画像に当たるかは、条文の文からは決まりません。

意匠法第23条は、意匠権の効力を次のように定めています（写しの全文）。

（意匠権の効力） 第二十三条 意匠権者は、業として登録意匠及びこれに類似する意匠の実施をする権利を専有する。 ただし、その意匠権について専用実施権を設定したときは、専用実施権者がその登録意匠及びこれに類似する意匠の実施をする権利を専有する範囲については、この限りでない。

二つの頁は、見た目を使って何かを売ることも貸すこともしません。他人の登録意匠と照らし合わせては確かめていません。

不正競争防止法第2条第1項第1号と第2号は、次のとおりです（写しの全文）。

一 他人の商品等表示（人の業務に係る氏名、商号、商標、標章、商品の容器若しくは包装その他の商品又は営業を表示するものをいう。以下同じ。）として需要者の間に広く認識されているものと同一若しくは類似の商品等表示を使用し、又はその商品等表示を使用した商品を譲渡し、引き渡し、譲渡若しくは引渡しのために展示し、輸出し、輸入し、若しくは電気通信回線を通じて提供して、他人の商品又は営業と混同を生じさせる行為

二 自己の商品等表示として他人の著名な商品等表示と同一若しくは類似のものを使用し、又はその商品等表示を使用した商品を譲渡し、引き渡し、譲渡若しくは引渡しのために展示し、輸出し、輸入し、若しくは電気通信回線を通じて提供する行為

二つの頁は、ロゴも標章も持ちません（部品の一覧）。他人の商品等表示を、自分の表示として使っていません。

不正競争防止法第2条第1項第3号は、次のとおりです（写しの全文）。

三 他人の商品の形態（当該商品の機能を確保するために不可欠な形態を除く。）を模倣した商品を譲渡し、貸し渡し、譲渡若しくは貸渡しのために展示し、輸出し、輸入し、又は電気通信回線を通じて提供する行為

二つの頁は、商品を譲渡も提供もしません。style.css はこのリポジトリで書いたもので、ほかのサイトの CSS を写したという記録はありません。似た見た目のサイトがほかにあるかは、確かめていません。

見やすさ

障害を理由とする差別の解消の推進に関する法律（以下、障害者差別解消法）の第2条から、第1号と第2号を写しから切り出しました。

一 障害者 身体障害、知的障害、精神障害（発達障害を含む。）その他の心身の機能の障害（以下「障害」と総称する。）がある者であって、障害及び社会的障壁により継続的に日常生活又は社会生活に相当な制限を受ける状態にあるものをいう。

二 社会的障壁 障害がある者にとって日常生活又は社会生活を営む上で障壁となるような社会における事物、制度、慣行、観念その他一切のものをいう。

障害者差別解消法第2条から、第7号も写しから切り出しました。

七 事業者 商業その他の事業を行う者（国、独立行政法人等、地方公共団体及び地方独立行政法人を除く。）をいう。

障害者差別解消法第8条は、次のとおりです（写しの全文）。

（事業者における障害を理由とする差別の禁止） 第八条 事業者は、その事業を行うに当たり、障害を理由として障害者でない者と不当な差別的取扱いをすることにより、障害者の権利利益を侵害してはならない。 ２ 事業者は、その事業を行うに当たり、障害者から現に社会的障壁の除去を必要としている旨の意思の表明があった場合において、その実施に伴う負担が過重でないときは、障害者の権利利益を侵害することとならないよう、当該障害者の性別、年齢及び障害の状態に応じて、社会的障壁の除去の実施について必要かつ合理的な配慮をしなければならない。

運営者が障害者差別解消法第2条第7号の「事業者」に当たるかは、条文の文からは決まりません。この頁は、それを決めつけません。

そのうえで、二つの頁がしていることのうち、check_design.js が確かめている事柄だけを書きます。

  • 色だけに頼りません。style.css は、リンクの下線を消す定め（text-decoration）を持ちません。太字は、字の太さ（font-weight: 600）で示します。
  • 動くものがありません。style.css に animation・transition・@keyframes はありません。CSP の script-src 'none' で、スクリプトも動きません。動くものが無いので、動きを減らす設定（prefers-reduced-motion）に応じる定めも置いていません。
  • 代替文の要る要素がありません。img・svg・picture・video・canvas の要素はありません。
  • 操作できるのはリンクだけです。正の値の tabindex を付けていません。フォーカスの輪郭を消す定め（outline: none や outline: 0）はありません。
  • 拡大を止める定めはありません。viewport の meta に maximum-scale と user-scalable を置いていません。
  • 二つの頁の html の lang は ja です。
  • style.css は暗い配色（:root[data-theme="dark"]）も定めています。どの頁も data-theme を付けず、スクリプトも動かないので、その配色は使われません。上の表にも入れていません。

読み上げのソフトでの聞こえ方、実際の端末での拡大の表示、色覚の違いによる見え方は、確かめていません。

人と団体

二つの頁に、実在の人の肖像はありません。実在の団体のロゴや印もありません。画像の要素が無いためです。名は文字で書くだけです。

変わったとき

部品を変えたときは、この頁と verification/check_design.js を同じ PR で直します。部品とは、index.html、style.css、この頁、書体の並び、色のことです。この頁の表と実際のファイル・色・書体がずれれば、check_design.js が落ちます。
